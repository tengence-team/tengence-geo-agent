## 详细粒度硬性要求（违反即不合格）

1. **问题点逐项展开**：诊断报告 §11 的每条 P0/P1 必须在对应技术章节找到"现状证据（引用诊断原文）→ 落地方案（具体动作+涉及系统/配置）→ 实施步骤（编号）→ 验收标准（可勾选）"四段式，禁止一句话概括。
2. **关键词矩阵必须给词**：10.3 六子类每类列出**具体关键词**（中文+英文），不得只写"<品类>厂家"这类空占位；占位仅允许在极少数无法推断处出现并标注。
3. **工作量必须量化**：17.2 人日矩阵以模块为行、角色为列，数值与角色合计必须自洽（合计=各列求和=各模块求和）；修复路线约 24–30 人日、重建路线约 32–40 人日（参考范本规模）。
4. **落地配置必须是成品**：Nginx、robots、JSON-LD、hreflang、llms.txt 均以可直接粘贴的代码块给出，域名/证书路径按实际站点替换并注明。
5. **证据纪律**：诊断报告无证据处标注"待验证/待补充"；AI 引用测试、SERP 抽样等外部观察项标注来源与时间。
