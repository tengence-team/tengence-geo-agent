## 默认参数口径（人工复核时可调整）

- 关键词矩阵规模：约 200 词（英文约占 45%）；文章总量 ≤ 200 篇（中文 55–110 + 英文 45–60）。
- 周期：一个半月约 7 周（止血+基建 W1–2 / 模板修复或重建 W3–5 / 内容+多语 W4–7）。
- 多语言：仅中文（zh-CN）与英文（en）双语，英文由 AI 翻译 + 人工审核，不引入第三方专业翻译。
- 报价（quote:true）：默认人日单价参考 2026 年一线城市外包口径（项目经理 ¥1,260 / UI 设计 ¥1,400 / 前端 ¥1,490 / 运维 ¥1,150 / SEO 策略师 ¥1,830 / SEO 运营 ¥970），验收后 30 天免费 Bug 修复，年度维保 = 合同费用 10%。
- 证据纪律：诊断报告无证据处一律输出"待验证/待补充"，绝不编造数值；AI 引用测试、SERP 抽样等外部观察项须在落地时实测。
